```text
python tools/build_portable.py   بناء حزمة ويندوز بدون تثبيت (انظر docs/WINDOWS.md)
start.bat                 المحل الحقيقي (http://127.0.0.1:8765)
start-training.bat        التدريب المنفصل (http://127.0.0.1:8766)

python tools/syncctl.py status | join | restore   النسخة السحابية الاختيارية (docs/CLOUD_SYNC.md)
```

## الموجود فعليًا

- بحث موثق يميز المصادر المقروءة من الافتراضات ونقاط التحقق المحلي.
- خطة شاملة، قواعد التشغيل، التصميم، معايير الاختبار والإطلاق.
- ملف متغيرات التصميم الأصلي من أحدث أصل مدموج ليوسف، مع توثيق المصدر.
- خادم محلي بالمكتبة القياسية وقاعدة SQLite: استلام، وردية، بيع بالمسح، دفع مختلط، إيصال، مرتجع، تقطيع، طواجن بوصفات وعبوات وملصقات، استدعاء، جرد أعمى، تقارير، نسخ واستعادة.
- واجهة عربية/إنجليزية بتصميم يوسف، نهاري وليلي، مساعدة لكل شاشة، ومعالج اختبار الماسح.
- أداة فحص بيئة ويندوز قبل اتخاذ قرارات التنفيذ.

## التشغيل والاختبار الحالي

```text
python -m unittest discover -s tests -v
powershell -NoProfile -File tools/Discover-Environment.ps1
```

حزمة ويندوز بدون تثبيت تُبنى بـ `tools/build_portable.py` وتضم بايثون الرسمي؛ لم تُجرب بعد على جهاز عميل نظيف. بيانات التدريب منفصلة عن بيانات المحل. التشغيل المستهدف محلي على ويندوز دون اشتراك في خدمات نماذج أو إنترنت إلزامي.
