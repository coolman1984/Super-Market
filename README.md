# سوبر ماركت 🛒🥩

أساسات برنامج مصري لإدارة السوبر ماركت، واللحوم الطازجة، والطواجن النيئة المتبلة الجاهزة للتسوية.

## الموجود فعليًا

- بحث موثق يميز المصادر المقروءة من الافتراضات ونقاط التحقق المحلي.
- خطة شاملة، قواعد التشغيل، التصميم، معايير الاختبار والإطلاق.
- ملف متغيرات التصميم الأصلي من أحدث أصل مدموج ليوسف، مع توثيق المصدر.
- نواة تجريبية لقواعد المخزون والتحضير والتتبع واختباراتها. راجع توثيقها داخل الكود وحدودها في وثيقة المعمارية؛ ليست نظام محاسبة أو كاشير كاملًا.
- أداة فحص بيئة ويندوز قبل اتخاذ قرارات التنفيذ.

## التشغيل والاختبار الحالي

```text
python -m unittest discover -s tests -v
powershell -NoProfile -File tools/Discover-Environment.ps1
```

لا توجد حاليًا شاشة بيع أو خادم أو نسخة تثبيت. بيانات التجربة المستقبلية منفصلة عن بيانات المحل. التشغيل المستهدف محلي على ويندوز دون اشتراك في خدمات نماذج أو إنترنت إلزامي.
