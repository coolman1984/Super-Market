# توافق ماسحات الباركود 🏷️

آخر تحديث: ٣١ أكتوبر ٢٠٢٦ — الإصدار 0.1.1-pilot (الموازين في القسم ٥ب).

**الخلاصة الصادقة:** البرنامج مبني على طرق اتصال عامة، لا على ماركة. **لم يُختبر أي ماسح فعلي حتى الآن**؛ كل ما في العمود «الحالة» مبني على اختبارات محاكاة آلية ودليل الشركة المصنعة. الضمان التجاري يقتصر على ما يُنقل لاحقًا إلى «مختبر فعليًا» بجهاز حقيقي.

## الحالات الأربع

| الحالة | المعنى |
|---|---|
| ✅ مختبر فعليًا | جُرب بجهاز حقيقي في المحل أو المعمل، مع تاريخ وإصدار ونتيجة مسجلة |
| 🟡 مدعوم بالطريقة العامة ولم يُختبر هذا الطراز | طريقة الاتصال مدعومة ومختبرة بمحاكي؛ الطراز نفسه لم يُجرب |
| 🟠 يحتاج تعريفًا أو محولًا | يعمل بعد تعريف الشركة (منفذ افتراضي) أو تغيير وضع الماسح أو محول |
| ⛔ غير مدعوم | لا يعمل في هذا الإصدار؛ البديل مكتوب |

## ١. طرق الاتصال

| طريقة الاتصال | كيف يستقبلها البرنامج | الحالة | الدليل الحالي |
|---|---|---|---|
| USB سلكي يحاكي لوحة المفاتيح (HID Keyboard) | خانة مسح في المتصفح + نهاية Enter/Tab + حرف بداية اختياري | 🟡 | اختبار متصفح آلي يكتب الرمز + Enter؛ تكرار المسح يزيد الكمية؛ الرمز في خانة المبلغ يُرفض |
| لاسلكي 2.4 جيجا بقاعدة استقبال USB تحاكي لوحة المفاتيح | نفس السابق | 🟡 | نفس السابق؛ القراءات المخزنة تُرسل كمسحات عادية |
| بلوتوث بوضع لوحة مفاتيح (HID) | نفس السابق بعد الاقتران من ويندوز | 🟡 | لا نفترض أن كل ماسح بلوتوث بهذا الوضع |
| بلوتوث بوضع المنفذ التسلسلي (SPP) | منفذ COM افتراضي من ويندوز → خدمة المنافذ في البرنامج | 🟡 | اختبار منفذ افتراضي (pty) على لينكس، وقراءة مجزأة بطيئة |
| RS-232 منفذ COM حقيقي | خدمة المنافذ: السرعة والتكافؤ والبتات وبت التوقف والنهاية | 🟡 | نفس الكود؛ **مسار ويندوز (ctypes/kernel32) لم يُجرب على ويندوز** |
| USB بمنفذ COM افتراضي (CDC/VCP) | خدمة المنافذ بعد تعريف الشركة | 🟠 | يحتاج تعريف المصنّع أحيانًا (Honeywell/Zebra CDC) أو محول USB-RS232 (FTDI/Prolific/CH340) |
| شبكة TCP بنص خام | اتصال عميل بعنوان محلي ومنفذ، إعادة اتصال تلقائية | 🟡 | اختبار مقبس محلي + فصل وإعادة اتصال |
| USB HID-POS (ليس لوحة مفاتيح) | — | ⛔ | البديل: مسح رمز برمجة الماسح لتحويله إلى «USB Keyboard» أو «USB CDC/VCP» من دليله |
| بروتوكولات خاصة (SNAPI, OPOS, JPOS, IBM) | — | ⛔ | لا نربط البرنامج بحزمة شركة؛ استخدم وضع لوحة المفاتيح أو COM |
| ماسح مدمج في جهاز كاشير أندرويد | — | ⛔ | البرنامج يعمل على ويندوز؛ لم يُجرب كاشير أندرويد |

## ٢. ما يتعامل معه البرنامج داخل القراءة

| الحالة | السلوك |
|---|---|
| الأصفار الأولى | تُحفظ كنص؛ لا يتحول 012345678905 إلى 12345678905 |
| ١٢ مقابل ١٣ مقابل ١٤ رقمًا لنفس السلعة | **لا توحيد صامت**؛ يظهر «رمز مشابه يحتاج ربطًا» مع المرشحين، أو يفعّل المالك قاعدة التوحيد صراحة |
| رقم التحقق | يُفحص لرموز EAN/UPC/ITF-14 والملصقات الوزنية وعبوات المحل؛ الخطأ = «رمز تالف أو قراءة ناقصة» |
| UPC-E (٨ أرقام) | يُفك إلى UPC-A للبحث؛ يُحفظ كما قُرئ |
| حروف عربية بدل إنجليزية (لغة ويندوز عربية) | يُرفض مع رسالة؛ يمكن تفعيل «تصحيح لوحة المفاتيح العربية 101» **لهذا الماسح فقط** — لا نغيّر لغة المستخدم |
| أرقام عربية ٠١٢٣ | تُحوّل لأرقام قياسية |
| بادئة ونهاية | حرف بداية اختياري يلتقط المسح خارج الخانة؛ النهاية Enter أو Tab (لوحة مفاتيح) أو CR/LF/CRLF/TAB/ETX/EOT (منفذ) |
| فاصل المجموعات GS / FNC1 | يقبل الحرف 0x1D أو بدائل نصية `<GS>` و`^]` |
| معرف نوع الرمز (AIM مثل ]C1 ]d2 ]Q3) | يُفصل ويُعرض إذا فعّلته في إعداد الماسح |
| حقول GS1 | 01 الرقم، 10 الدفعة، 17 الانتهاء، 11/13/15 تواريخ، 21 تسلسل، 310n الوزن، 392n السعر، 00 SSCC، 30/37 العدد |
| رابط أو QR فيه نص | لا يُفتح ولا يُعتبر صنفًا تلقائيًا |
| مسحتان متتاليتان لنفس الباركود | قطعتان (تزيد الكمية) — لا تُسقط بسبب قرب الزمن |
| نفس حدث المنفذ يصل مرتين | يُستقبل مرة واحدة (لكل حدث رقم) |
| عبوة المحل الفريدة | لا تُضاف مرتين للسلة ولا تُباع مرتين حتى من كاشيرين |
| مسح أثناء نافذة الدفع أو الموافقة | يُتجاهل مع تنبيه؛ لا يدفع ولا يوافق ولا يعدّل المبلغ؛ رمز طويل مكتوب في خانة المبلغ يُمسح |
| قراءة مجزأة أو بطيئة على المنفذ | تُجمع حتى النهاية؛ الجزء المعلق أكثر من مهلة يُسقط ويُعد ولا يلتصق بالمسح التالي |
| قراءة طويلة جدًا أو رموز تحكم | تُرفض؛ الحد ٥١٢ حرفًا |
| فصل الجهاز وإعادة توصيله | الحالة «غير متصل — يحاول» ثم «متصل» تلقائيًا |
| ملصق ميزان | قالب يضبطه المحل من ملصق حقيقي: البادئة وموضع كود الصنف والقيمة ونوعها والخانات العشرية. **لا توجد بادئة عامة مفترضة** |
| ملصق سعر بدون وزن | لا خصم مخزني تخميني (السياسة الافتراضية: منع) |
| ملصق عبوة سعر قديم | يُباع بسعر الملصق وتظهر رسالة الفرق (سياسة قابلة للضبط) |

## ٣. الرموز حسب قدرة الجهاز

قارئ الرمز شيء ومحلل البيانات شيء آخر: البرنامج يفهم النص، لكنه لا يمنح ماسحًا خطيًا القدرة على قراءة الرموز المربعة.

| الرمز | ماسح ليزر/خطي 1D | ماسح صور 2D | البرنامج |
|---|---|---|---|
| EAN-13 / EAN-8 / UPC-A / UPC-E | نعم عادة | نعم | فحص رقم التحقق |
| ITF-14 (كرتونة) | حسب التفعيل | نعم | فحص رقم التحقق |
| Code 128 / Code 39 | نعم عادة | نعم | نص كما هو |
| GS1-128 | نعم إذا أرسل FNC1/GS | نعم | تحليل الحقول |
| GS1 DataBar | حسب الطراز | حسب الطراز | يُحلل كعناصر GS1 إذا أرسل الماسح GS |
| QR / Data Matrix (و GS1 DataMatrix) | **لا** | نعم | QR نصي لا يُعتبر صنفًا؛ GS1 DataMatrix يحلل |

## ٥. اختبارات المحاكاة الموجودة

`tests/test_scanner.py` و`tests/ui/smoke.js`: الأصفار، ١٢/١٣ دون توحيد، رقم تحقق تالف، أرقام عربية، لغة لوحة مفاتيح عربية مع التصحيح وبدونه، GS1 مع GS وبدائله ومعرف AIM وتاريخ اليوم 00، ملصقات وزن وسعر وقالب متداخل، روابط، UPC-E، عرض رموز التحكم، قراءة مجزأة، بادئة STX ونهاية CRLF، جزء معلق يُسقط، وضع بلا نهاية بالمهلة، قراءة طويلة، منفذ تسلسلي افتراضي، TCP مع فصل وإعادة اتصال وتكرار مسح مقصود، عبوة فريدة مكررة، صنف مشابه يحتاج ربطًا، مسح باركود داخل خانة المبلغ.

## ٥ب. الموازين (٣١ أكتوبر ٢٠٢٦)

لم يُجرَّب أي ميزان حقيقي بعد. الحالة 🟡 = الطريقة مدعومة ومختبرة بمحاكي، والطراز نفسه لم يُجرَّب.

| النوع | أمثلة متداولة | كيف يستقبله البرنامج | الحالة |
|---|---|---|---|
| ميزان يطبع ملصق باركود EAN-13 | CAS سلسلة CL، DIGI سلسلة SM، Aclas سلسلة LS، Rongta RLS، Mettler Toledo bPlus/Tiger، Dibal، Bizerba | الماسح يقرأ الملصق؛ الشكل يُعرف من ملصق واحد حقيقي (`server/scale.py: detect_label_layout`) | 🟡 |
| ميزان كاشير يرسل الوزن وحده (RS-232 أو USB-COM) | أغلب موازين الكاشير الصينية، أسلوب CAS `ST,GS,+  1.250kg` | منفذ COM، `poll: none` | 🟡 (منفذ افتراضي) |

## ٦. بوابة العتاد (مفتوحة)

لكل طريقة اتصال جهاز حقيقي واحد على الأقل: سلكي لوحة مفاتيح، لاسلكي بقاعدة، بلوتوث HID، بلوتوث SPP، COM/USB-CDC، وشبكة إن وجد. لكل جهاز: الطراز والإصدار، لغة ويندوز، ورقة الاختبار كاملة، ١٠٠ مسح متتالٍ دون فقد، فصل وإعادة توصيل، مسح أثناء الدفع، ثم نقل السطر إلى «مختبر فعليًا» بالتاريخ.
