السوبر ماركت — نسخة ويندوز بدون تثبيت
=========================================

1) فك الضغط في مجلد تملكه، مثل:  C:\SuperMarket
   (لا تضعه في Program Files ولا على مجلد شبكة.)
2) اضبط منطقة ويندوز الزمنية على: (UTC+02:00) Cairo
3) شغّل: start.bat
   تفتح نافذة صغيرة باسم البرنامج — لا تغلقها أثناء العمل — ثم يفتح المتصفح.
4) أول مرة: اكتب اسم المحل وأنشئ حساب صاحب المحل.

التدريب:        start-training.bat   (بيانات تدريب منفصلة عن بيانات المحل)
تدريب من جديد:  start-training-reset.bat (يحتفظ بالتدريب السابق في مجلد مستقل)
أمين صندوق ثانٍ: start-lan.bat على الجهاز الرئيسي فقط (راجع docs\WINDOWS.md)
الإيقاف:        أغلق نافذة البرنامج.
ملاحظة:         لا ينشئ البرنامج اختصارًا على سطح المكتب؛ افتح start.bat من المجلد.
النسخ:          نسخة يومية تلقائية في backups-shop (وأخرى مجدولة إن بقي البرنامج يعمل أيامًا)، وانقلها لمكان آخر أسبوعيًا.
التحديث:        فك ضغط النسخة الجديدة فوق نفس المجلد واختر "استبدال".
                بياناتك في shop-data لا يلمسها التحديث، ويُحفظ نسخة قبل أول تشغيل للإصدار الجديد.

Super Market — portable Windows build (no installation)
Unzip to a folder you own (e.g. C:\SuperMarket), set the Windows time zone to Cairo,
run start.bat. Training: start-training.bat. Details: docs\WINDOWS.md
