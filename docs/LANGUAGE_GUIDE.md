# دليل اللغة والمصطلحات

تحديث 31 أكتوبر 2026: لغة ما يراه صاحب المحل **مصرية بسيطة جدًا**. جملة قصيرة وكلمة يقولها صاحب بقالة. هذا قرار المالك، ويحل محل طلب الفصحى الرسمية.

- الجملة قصيرة، وفيها فعل واحد. بلا «يُرجى» وبلا «نظرًا» وبلا ترجمة حرفية.
- كلمات المحل: الكاشير، أمين الجرد، فلوس أول الوردية، قفل الوردية، حد الآجل. الوزن الصافي والحجز للفحص والاستدعاء تبقى بأسمائها القصيرة المفهومة.
- قاموس العربية مستقل عن الإنجليزية، والمفاتيح والمتغيرات واحدة. الأرقام أرقام، والوحدة مكتوبة.
- رسالة الخطأ تقول ماذا حصل وماذا يعمل الآن. إذا اترفضت العملية قبل الحفظ، قول ذلك.
- كل شاشة لها غرض وخطوات بأسماء الأزرار الظاهرة، ومثال، وعلامة نجاح، وتصحيح آمن.
- لا تقل له يخترع فاقدًا، ولا مدة صلاحية قانونية من عندنا.
- لا تقل إن وضع النسخة في الطابور يعني أنها اتحفظت على السحابة.
- شاشات البرنامج والمرشد الداخلي بالمصرية البسيطة. وثائق الدعم للمطوّر يمكن أن تكون أوضح وأطول، بلا شتيمة وبلا تعقيد.
- الفحص الآلي يثبت القرار ده، ومراجعة المعنى لسه لازمة.

الفحص: `python -m unittest discover -s tests -p test_language.py`، وفحص المرشد: `python -m unittest discover -s tests -p test_guide_gate.py`.
