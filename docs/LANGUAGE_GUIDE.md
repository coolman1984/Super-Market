# دليل اللغة والمصطلحات

القواعد التي تحميها `tests/test_language.py`:

1. **قاموسان منفصلان** بالمفاتيح نفسها: `web/js/i18n/ar.js` للعربية الميسّرة داخل المنتج، و`en.js` للإنجليزية. لا إنجليزية داخل جملة عربية.
2. **الأرقام بالأرقام** في اللغتين (5 دقائق، 8 أحرف) حتى تتطابق المعاني والقيم.
3. **المصطلحات الموحدة:** أمين الصندوق، مسؤول الجرد، رصيد بداية الوردية، إغلاق الوردية، الحد الائتماني، الوزن الصافي، حجز للفحص، استدعاء. للتحصيل «دفعة سداد» لا «دفعة».
4. **محظور:** اقفل، الفكة، الكاشير، الجارد، حد الآجل، كده، دلوقتي، إزاي، مفيش، اللي، برضه، وأي إشارة إلى اختصار سطح المكتب.
5. **ممنوع** أي نص يطلب اختراع فاقد ليتوازن الوزن؛ القاعدة: قِس، راجع، لا تعتمد حتى يُعرف السبب.
6. **رسالة الخطأ = السبب + أثر الحفظ:** إما «لم يُحفظ شيء» أو «النتيجة غير مؤكدة، راجع قبل الإعادة». لكل رمز خادم مفتاح `err.<code>`.
7. **بنية الشرح لكل شاشة:** الغرض، ما يلزم قبل البدء، الخطوات (مرتبطة بأزرار حقيقية عبر `{b:key}`)، مثال برقم، الأخطاء الشائعة، التصحيح الآمن، علامة النجاح، الخطوة التالية بحسب دور المستخدم وحالته.
8. **الرد لصاحب المشروع** بالمصرية المختصرة؛ هذا خارج المنتج.

للإضافة: أضف المفتاح في الملفين معًا، وشغّل `python -m unittest test_language`.
