# دليل اللغة والمصطلحات

تحديث 31 أكتوبر 2026: لغة المنتج وأدلته **فصحى رسمية واضحة ومحترمة**. يحل هذا التوجيه محل السماح السابق بالعامية المحترمة. يظل الرد لصاحب المشروع بالمصرية المختصرة خارج نصوص المنتج.

- الجملة قصيرة، مباشرة، وتذكر فعلًا واحدًا أو قرارًا واضحًا. لا عبارات بيروقراطية ولا ترجمة حرفية.
- المصطلحات المعتمدة: أمين الصندوق، مسؤول الجرد، رصيد بداية الوردية، إغلاق الوردية، الحد الائتماني، الوزن الصافي، حجز للفحص، استدعاء، إشعار دائن، طاجن نيء جاهز للتسوية. للتحصيل «دفعة سداد»؛ وللتتبع «دفعة مخزون».
- قاموس العربية مستقل عن الإنجليزية، مع تطابق المفاتيح والمتغيرات والوحدات. الأرقام رقمية ووحداتها صريحة.
- رسالة الخطأ تشرح السبب والخطوة الآمنة. إذا رُفضت المعاملة قبل الحفظ يُذكر ذلك؛ وعند انقطاع الرد يقال إن النتيجة غير مؤكدة وتُستعلم قبل التكرار.
- لكل شاشة غرض ومتطلبات وخطوات بأسماء الأزرار الفعلية ومثال وعلامة نجاح وتصحيح آمن وخطوة تالية بحسب الدور.
- لا توصية باختراع فاقد أو تغيير تصنيف سلعة للتحايل على التحقق، ولا مدة صلاحية تدريبية موصوفة بالاعتماد.
- لا ادعاء بأن وضع النسخة في الطابور يؤكد حفظها على السحابة، أو بأن محاكاة الماسح اختبار لجهاز حقيقي.
- تحمي اختبارات اللغة القواميس والمرشد والأدلة الحالية من العبارات العامية المعروفة. الفحص الآلي لا يغني عن المراجعة التحريرية للمعنى.

الفحص: `python -m unittest discover -s tests -p test_language.py`، وفحص المرشد: `python -m unittest discover -s tests -p test_guide_gate.py`.
