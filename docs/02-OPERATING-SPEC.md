# مواصفات التشغيل: من الاستلام إلى قفل اليوم 🛒🥩

كل القواعد التالية **تصميم تشغيلي مقترح**، وليست ادعاءً بأن كل محلات مصر تعمل بالطريقة نفسها. المقابلات الميدانية والتحقق الغذائي والضريبي في سجل البحث جزء من قبول النسخة.

## ١. القوائم الأساسية

| الكيان | البيانات الضرورية |
|---|---|
| الصنف | كود داخلي، اسم عربي وإنجليزي، قسم، وحدة أساس، نوع: بقالة/خام/محضر، بيع وزني أو عددي، اشتراط دفعة وصلاحية، حد إعادة طلب |
| وحدات التعبئة | قطعة/عبوة/كرتونة ومعامل تحويل مضبوط، باركود لكل تعبئة، تاريخ تفعيل التحويل؛ المعامل المحفوظ في الفاتورة لا يتغير لاحقًا |
| الدفعة | المورد، رقم دفعته ورقم داخلي، تاريخ الاستلام، تاريخ الإنتاج إن وجد، تاريخ أو وقت الانتهاء، مصدر ومرجع تحديده، حالة الإفراج، تكلفة الاستلام |
| المكان | رف، مخزن، ثلاجة عرض، ثلاجة تجهيز، تجميد، حجر فحص، هالك؛ إمكان البيع صريح ولا يرتبط بالاسم |
| الوصفة | إصدار ثابت، مدخلات وأوزان، بدائل مسموحة، مسببات حساسية، ناتج مستهدف، سماح هالك، سياسة صلاحية معتمدة، ملصق |
| العميل | الاسم والهاتف اختياريان للبيع النقدي؛ مطلوب تعريف واضح للبيع الآجل؛ حد ائتمان وضوابط استعمال البيانات |
| المورد | حساب، فواتير، دفعات، خصومات وإشعارات دائنة، آجال سداد، مستندات توريد |
| مستخدم/وردية/جهاز | الدور والصلاحيات، درج الوردية، بداية الفكة، الجهاز، حالة الاتصال |

الموظفون: مالك، مدير، كاشير، مستلم، جزار/محضر، جارد، محاسب، قارئ تقارير. مصفوفة مستقلة للقراءة والكتابة والتصدير. المحضر لا يرى هامش الربح افتراضيًا، والجارد يعدّ دون رؤية الرصيد المتوقع.

## ٢. شراء واستلام البقالة

طلب شراء اختياري → استلام فعلي → مطابقة فاتورة المورد → مراجعة الفروق → سداد أو مديونية → متابعة إشعارات المورد.

- الاستلام يقبل جزئيًا ويعرض المرتجع/المرفوض وأسبابه. الطلب وحده لا يزيد المخزون.
- فصل تاريخ الفاتورة عن تاريخ الاستلام والترحيل، مع فترة إقفال تمنع التأريخ الرجعي دون إذن.
- مثال: كرتونتان كل منهما ١٢ عبوة = ٢٤ عبوة. عبوتان مجانيتان تصلان بالمخزون إلى ٢٦؛ تكلفة الفاتورة موزعة على المستلم وفق سياسة معلنة. لا تفترض أن المجاني بلا أثر على متوسط التكلفة.
- خصم سطر، خصم فاتورة، شحن ومصاريف شراء، وضريبة قابلة للاسترداد أو غير قابلة حسب التصنيف المعتمد. لا تجمعها جميعًا كمصروف أو كتكلفة تلقائيًا.
- نفس الصنف قد يصل بدفعات وتواريخ مختلفة. لا تدمج الدفعات لمجرد تشابه الاسم أو الباركود.
- إدخال فاتورة مورد مكررة يُنبه بمورد+رقم+تاريخ، ولا يحظر رقمًا مكررًا من مورد آخر.
- تأخر فاتورة المورد بعد الاستلام يحتاج تسوية تكلفة مراجعة، مع أثر واضح على تكلفة المبيعات السابقة بدل إعادة كتابة القيود.

## ٣. استلام اللحوم

اختيار المورد ومستند المصدر → وزن إجمالي → وزن عبوة/تعليق/وعاء → صافي مقبول → فحص واستلام أو حجر/رفض → دفعة ومكان حفظ.

سجل الفحص يدعم المستندات والملاحظات ودرجة الحرارة المقاسة والجهاز والقائم بالفحص، وفق سياسة المحل المعتمدة. البرنامج لا يقرر سلامة اللحوم من الوزن أو الصورة. لا نعتمد أرقام حرارة أو صلاحية افتراضية كحقيقة قانونية.

تمييز طريقة الشراء: قطع صافية، بعظم، ربع/ذبيحة، أو لحمة مفرومة. هذا يحدد وحدات الاستلام وأمر التقطيع؛ لا تقارن سعر كيلو الذبيحة بسعر كيلو الصافي مباشرة.

التجميد أو فك التجميد أو فتح العبوة **تغيرات حالة** مسجلة بتاريخ وسبب وسياسة، لا زر لتمديد الصلاحية. الدفعة المحجوزة للفحص لا تباع ولا تدخل وصفة.

## ٤. التقطيع والتشفية

أمر تقطيع واحد يربط دفعة أو أكثر بمخرجات: قطع، مفروم، دهون، عظام، وفاقد غير قابل للبيع. سجّل الوزن الفعلي لكل مخرج؛ لا تُخفِ العظم المباع في خانة هالك.

معادلة وزن أمر التقطيع:

**المدخل = مجموع المخرجات القابلة للتتبع + الفاقد المعتمد**.

وزن الوعاء مستبعد من البداية. تجاوز السماح يوقف الترحيل حتى مراجعة المدير؛ لا يُخصم فرق مجهول بصمت. معاملات التحويل الوصفية مثل «كيلو خام ينتج ٨٠٠ جرام» للتخطيط فقط؛ القيد يعتمد الوزن الفعلي.

توزيع التكلفة قرار مثبت لكل أمر: الوزن النسبي افتراضي واضح، أو القيمة البيعية النسبية المعتمدة عندما تختلف قيمة القطع والعظم. المنتج الثانوي له تكلفة وفق السياسة؛ الفاقد الطبيعي يحمل على المخرجات، والفاقد غير الطبيعي يسجل خسارة مستقلة. يحتفظ الأمر بالطريقة والأوزان والقيم والموافقات. النواة الأولية لا تنفذ كل بدائل التقييم.

## ٥. تصنيع الطواجن النيئة المتبلة

أمر تجهيز → اختيار إصدار الوصفة → تخصيص دفعات اللحم والبصل والزيت والتوابل وغيرها → تسجيل الاستخدام الفعلي والبدائل → وزن الناتج وعدد العبوات → استهلاك الصواني والأغطية → اعتماد وإنتاج دفعة جاهزة → ملصق.

- نفرق بين وزن الطعام وصافي اللحمة ووزن العبوة؛ طاجن وزنه كيلو لا يعني كيلو لحمة.
- الوصفة المستهدفة لا تُخفي الاستهلاك الفعلي. تعديل الوصفة يصنع إصدارًا جديدًا ولا يغير تكلفة إنتاج قديم.
- الصلاحية النهائية = الأقرب بين المكونات الداخلة والمهلة المعتمدة للوصفة من وقت التجهيز، وقد تقصرها واقعة سلامة؛ لا تمدد الصلاحية تلقائيًا بسبب التتبيل أو التجميد.
- مكونات بلا صلاحية محددة تحتاج سياسة موثقة؛ لا تُعامل القيمة المفقودة كتاريخ بعيد.
- تغيير نوع تتبيلة أو بديل يستدعي مراجعة قائمة مسببات الحساسية والملصق قبل الإفراج.
- التسعير بالكيلو أو بالطاجن إعداد مستقل. الطواجن متفاوتة الوزن لها تعريف عبوة فريد ووزن فعلي، لا نفترض وزنًا ثابتًا.
- المخزون ينقص من المكونات **عند ترحيل الإنتاج** ويزيد من الجاهز؛ عند البيع ينقص الجاهز فقط. التحضير عند الطلب مسار مستقل يستهلك الخام مرة واحدة داخل معاملة البيع.
- أمر فشل أو انقطع أثناء ترحيله لا يترك نصف استهلاك أو ناتجًا بلا تكلفة.
- تعديل ملصق أو إعادة تعبئة لا يخلق مخزونًا ولا يمحو أصل الدفعة.

تخطيط التحضير يقرأ الطلب والمخزون الجاهز والصلاحية قبل اقتراح كميات. التنبؤ الأول بسيط ومفسر: متوسط بيع أيام مماثلة، ومهلة توريد، ومخزون أمان. رمضان والأعياد وعطلات الأسبوع عوامل تُضبط من بيانات المحل؛ لا نختلق نسب طلب للسوق.

## ٦. البيع السريع

فتح وردية بفكة → مسح باركود/بحث اسم/كود → كمية أو وزن → عرض السعر والخصم → وسيلة دفع → حفظ ذري → إيصال → بيع جديد.

أنواع المسح: باركود مورد ثابت، باركود تعبئة، ملصق وزن أو قيمة، باركود عبوة داخلية فريدة، ومعرفات معيارية عند دعمها. قالب الميزان إعداد معتمد للمحل: البادئة، كود الصنف، موضع البيانات، العلامة العشرية، وزن أم سعر، ورقم التحقق. لا تفترض أن كل بادئة تبدأ برقم محدد لها المعنى نفسه.

- ملصق يحمل السعر يحتاج سياسة صريحة: سعر وقت التعبئة، أم إعادة تسعير وقت البيع بعد موافقة وعرض الفرق. لا تستنتج الوزن من السعر إذا تغير سعر الكيلو.
- الملصق القيمى الذي لا يحتوي وزنًا يحتاج لقطة سعر التعبئة الموثوقة أو وزنًا مؤكدًا؛ وإلا يُمنع الخصم المخزني التخميني.
- الباركود المتكرر العادي قد يعني عبوتين فعلًا؛ لا تمنعه كخطأ. العبوة الداخلية ذات المعرف الفريد تُرفض إذا سبق بيعها.
- الأقرب انتهاءً يصرف أولًا للمنتج الفعلي من نفس مكان البيع. عند اختلاف الدفعات بالعرض يُطلب تأكيد الدفعة أو مسح ملصقها؛ تخصيص وهمي لا يساوي تتبعًا حقيقيًا.
- فاتورة معلقة لا تخصم مخزونًا إلا إذا طبق حجز ذو انتهاء محدد. عودة الشاشة أو إعادة إرسال الطلب لا تكرر البيع.
- أول نسخة نقدية افتراضيًا. البطاقات والمحافظ والتحويلات والآجل تُفعّل بإعداد وصلاحية ومراجعة، والدفع المختلط يدعم جزءًا نقديًا وجزءًا إلكترونيًا.
- لا تخزين لبيانات بطاقات بنكية. مرجع العملية وحالة تأكيدها فقط. الإشعار أو صورة التحويل لا يساوي تسوية مؤكدة.
- الباقي يحسب من النقد المستلم، لا من مجموع وسائل الدفع. مصروف شركة الدفع يظهر منفصلًا عن الخصم التجاري.
- منع البيع تحت الحد أو التكلفة حسب سياسة تتطلب موافقة موثقة، مع حفظ لقطة تكلفة وسعر وضريبة وخصم لكل سطر.

## ٧. الأسعار والعروض والتخفيض القريب من الانتهاء

سجل سعر مؤرخ، معاينة تغيير مجموعة أصناف، سعر قطاعي وجملة إذا لزم، وحد أدنى. السعر الجديد لا يغير الفواتير القديمة أو ملصقات العبوات دون إجراء واضح.

العرض: مدة، نطاق، حد كمية، أولوية وتعارض. النسخة الأولى تحتاج خصم سطر وفاتورة وعرض بسيط؛ عروض اشترِ واحصل وحزم مركبة تُنفذ بعد تحديد سياسة توزيع الخصم ورد الجزء. نسبة الخصم تتوزع بقروش صحيحة والباقي موزع حتميًا.

تخفيض قرب الانتهاء إجراء موافقة وتاريخ، وليس تمديدًا للصلاحية. يمنع بيع المنتهي حتى لو كان بسعر صفر.

## ٨. المرتجعات ورد المورد

مرتجع العميل مرتبط بسطر الفاتورة، كمية لم تُرد سابقًا، قيمة بعد نصيب الخصم، سبب، موافقة، وسيلة رد وسجل واضح. لا يرد أكثر مما استحقه العميل، ولا يُحوّل دين غير مدفوع إلى نقدية خارجة بلا قاعدة.

الحالة المادية مستقلة عن التسوية المالية: بقالة سليمة مغلقة بعد الفحص قد ترجع للبيع؛ اللحوم والطواجن تعود افتراضيًا للحجر/الفحص ولا يعاد بيعها آليًا. هذا إجراء احترازي تشغيلي، وليس تفسيرًا نهائيًا لحقوق المستهلك أو السماح الغذائي بإعادة البيع.

رد المورد: حجز كمية محددة من دفعة → إخراج فعلي → إشعار دائن أو مبلغ مستحق → مطابقة المورد. لا تخصم الدفعة بمجرد إنشاء طلب رد. تتبع رد جزئي واختلاف سعر الإشعار وتأخره.

## ٩. الجرد والتالف والاستدعاء

- جرد دوري أعمى حسب رف/ثلاجة/دفعة، مع وزن فعلي للأصناف الوزنية. غير المعدود ليس صفرًا.
- قبل الجرد: قطع نقطة ترحيل واضحة لكل مكان أو لكل سطر، مع منع حركة المنطقة لوقت قصير أو تسوية الحركات التالية بنقطة تسلسل قاعدة البيانات. التاريخ بالثانية وحده لا يكفي عند التزامن.
- عدّ ثانٍ للفروق الكبيرة بواسطة شخص آخر؛ لا يكشف الرصيد المتوقع للجارد الأول. الاعتماد يُنشئ قيد تسوية مستقلًا بسبب، ولا يعدل الاستلام أو البيع الأصلي.
- الأسباب: فاقد تقطيع طبيعي، فاقد غير طبيعي، انتهاء، تسريب/تلف عبوة، انقطاع تبريد، استهلاك داخلي، عينة، سحب مالك، فرق مجهول. لا تجمعها في «تالف» بلا تحليل.
- التالف لا يختفي من قيمة التقرير دون قيد خسارة واعتماد. الهالك المادي يحتاج سجل التخلص ومراجعه.
- استدعاء دفعة خام يعزل المخزون المتبقي **وكل المنتجات المنحدرة منها**، ويحدد الفواتير المتأثرة والعملاء المعروفين. لا نجمع أسماء جميع المشترين لمجرد احتمال الاستدعاء.
- الاستدعاء يمنع البيع والتحضير والتبديل عبر كل الأماكن؛ الإفراج عنه بصلاحية أعلى وسبب محفوظ، وبعد التحقق الغذائي اللازم.

## ١٠. الوردية والخزنة والحسابات

المتوقع في الدرج = الفكة + مبيعات الكاش + تحصيل الديون نقدًا + إيداع نقدي − ردود النقد − مصروفات الدرج − سداد المورد منه − التوريد للخزنة.

عدّ أعمى → إظهار الفرق → تفسير واعتماد → قفل؛ أي تعديل بعد القفل إجراء عكسي له فترة محاسبية واضحة. فتح الدرج دون بيع، إلغاء سطر بعد مسحه، إعادة طباعة، خصم، بيع خارج الوقت، وتكرار المرتجعات أحداث مراجعة، وليست حكمًا آليًا بالسرقة.

الآجل: كشف حساب من القيود، حد ائتمان، استحقاق، دفعة جزئية، سداد وإلغاء سداد بقيد عكسي. لا نحتاج تقسيط أجهزة وضامن وسيريال لتشغيل سوبر ماركت عادي.

مصروف التشغيل منفصل عن شراء المخزون، وسحب المالك ليس مصروف تشغيل. لا تعلن «صافي الربح» إذا لم تُسجل المصاريف وتكاليف الفاقد المطلوبة؛ اعرض «هامش إجمالي بعد الهالك المسجل» وما يستبعده بوضوح.

## ١١. تقارير صاحب المحل

اليوم: المبيعات الصافية، التحصيل حسب الوسيلة، هامش المبيعات، خسائر الهالك، المخزون القريب من الانتهاء، فروق الدرج، التحضيرات المنتظرة، الموردون المستحقون، وأخطاء سلامة التتبع.

تفاصيل: كارت صنف ودفعة، ربحية قسم ومنتج ووصفة، مردود التقطيع الفعلي مقابل المستهدف، تباين استهلاك الوصفة، تكلفة اللحمة الصافية، أعمار المخزون، نفاد وفرص مفقودة مسجلة، إعادة الطلب، فروق الجرد، الخصومات والإلغاءات والمرتجعات حسب المستخدم، والتحويلات غير المسواة.

كل رقم يفتح تفاصيله ومستنداته ويعرض الفترة والمرشحات. لا تخلط الضريبة المحصلة بالإيراد، ولا إجمالي المبيعات بالكاش، ولا المخزون بالحسابات الآجلة. جميع التقارير لها تصدير مضبوط بالصلاحية.
