# SM-02 — السعر صفر والنص غير المفهوم

قبل: سؤال «السعر صفر» ثم «سيُباع هذا الصنف مجانًا. هل أنت متأكد؟»، والنص `abc` يُغلق ويظهر «مبلغ غير صحيح» من غير اسم الخانة.
