# إثبات إصلاح مراجعة التشغيل — ٠٫١٫٢ التجريبي

تاريخ التنفيذ: ١ نوفمبر ٢٠٢٦. كود التشغيل المرشح: `c97d378f50ce1c76430ae93ba4f360a50385ce00`. تُحدّث الأدلة والوثائق بعده دون تغيير كود التشغيل داخل المثبت. دُمج إصلاح دورة اللوحات الأحدث من الفرع الرئيسي أيضًا.

## ما أُصلح

| الملاحظة | نتيجة التحقق |
|---|---|
| لحم في رف بقالة | رفض ذري دون استلام جزئي؛ الرصيد القديم غير الملائم لا يباع ويظهر للمراجعة |
| توقيت التحصيل | بيان مستقل حسب يوم التحصيل والتأكيد والعكس؛ بيان مبيعات اليوم يبقى منفصلًا ومسمى بوضوح |
| أسطر العرض المتطابقة | ٣ وحدات في سطر أو ثلاثة أسطر = ٣٠ جنيهًا؛ المرتجع يحافظ على قاعدة الوحدة المجانية |
| إجراءات الموظفين خارج العرض | بطاقات في الهاتف والجهاز اللوحي، دون تمرير أفقي للوصول إلى الإجراءات |
| حقول التجهيز والماسح | تبقى داخل البطاقة عند العرض الضيق |
| اختفاء لوحة جانبية جديدة | مؤقت إغلاق اللوحة السابقة لا يمحو اللوحة التي تليها؛ اختبار يستبدلهما قبل انتهاء الحركة |
| تعارض ترقيات الفروع | رقم سري ١٠، عجز وردية ١١، وربط التحصيل بالوردية ١٢؛ اختبار قواعد الفروع القديمة وحفظ الصفوف |

جُمعت الفروع التي كانت تحمل عملًا غير مدمج: عجز الوردية، ورقة الجرد، الدفع والإنستاباي، تحصيل الديون، تقرير المراجعة الحديث، وتقرير الاختبار القديم. بقية الفروع كانت داخلة بالفعل في تاريخ الفرع الرئيسي. حُفظت آباء الفروع بدل نسخ التغييرات وحدها.

## نتائج التنفيذ المحلي

- ٣٤٦ اختبار خادم ناجحًا، و٢٧ اختبارًا للخدمة السحابية، ونجاح فحص الواجهة الثابت.
- ١٢ سيناريو ضغط مستقلًا ناجحًا: ١٢٠٠ فاتورة، و٢٠٠ محاولة تنافس على الرصيد، و٢٥٠ إعادة إرسال، و٣٠٠ قراءة مشوّهة، وحالات التحصيل والجرد والاستدعاء.
- ٥٧ مشاهدة للصفحات في أربعة أوضاع، و٧ أدوار بجانب المالك؛ لا أخطاء تشغيل أو استجابات ٥٠٠ أو ملاحظات تجاوز حدود الحقول والأزرار في العينة النهائية.
- نسخ ٤٠١ بيعًا و٤٠ مرتجعًا مع فقد الرد بعد التخزين، ثم استعادة وتطابق عشرة جداول ورصيد ٦٣٩ وحدة. لا أخطاء مفاتيح خارجية ولا طابور رفع متبقٍ.

النتائج الخام بجوار هذه الوثيقة. سجل ويندوز والبناء منشور في [طلب الإصدار](https://github.com/coolman1984/Super-Market/pull/29)، وسير بناء النسخة المرشحة هو [بناء الإصدار على ويندوز](https://github.com/coolman1984/Super-Market/actions/runs/41274885885). لا يُستبدل نجاح لينكس بادعاء نجاح ويندوز؛ نتيجة كل مرحلة تؤخذ من سجلها المكتمل.
